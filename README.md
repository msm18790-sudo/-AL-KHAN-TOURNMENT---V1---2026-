# THE SQUARE — بطولة الخان 2026

واجهة عربية لإدارة بطولة من 12 إلى 16 فريقًا في أربع مجموعات من 3 أو 4 فرق. دوري من دور واحد داخل المجموعة: الفوز 3 نقاط، التعادل نقطة والخسارة صفر. يتأهل الأول والثاني من كل مجموعة إلى ربع النهائي ثم نصف النهائي والنهائي، مع مباراة للمركز الثالث.

## الاستخدام
1. سجل الفرق واللاعبين.
2. أجرِ القرعة بعد اكتمال 12–16 فريقًا؛ عدد المجموعات ثابت: أربع.
3. سجل نتائج المجموعات ثم افتح خروج المغلوب وراجع المتأهلين قبل تثبيتهم. الاختيار الافتراضي حسب النقاط وفارق الأهداف والأهداف والمواجهة المباشرة بين فريقين فقط. عند استمرار التعادل تحسم اللجنة السجل الانضباطي ثم القرعة التنظيمية يدويًا.
4. سجل نتائج ربع النهائي وأنشئ نصف النهائي، ثم النهائي والمركز الثالث. التعادل في الإقصائيات يتطلب نتيجة ترجيح حاسمة منفصلة.
5. النتائج السابقة تقفل بعد إنشاء المرحلة التالية. لإعادة اعتماد المسار، احذف الأدوار الإقصائية أولًا.

## اللوائح
صفحة الشروط واللوائح تعرض مواد الدليل التشغيلي السابق مع تحديث نظام المنافسة إلى أربع مجموعات بناءً على توجيه مالك البطولة. الدليل الأصلي لائحة مقترحة؛ تعتمد اللجنة الصيغة النهائية والجوائز والمواعيد قبل التعميم. النظام لا يتتبع العمر والبطاقات والإيقافات أو يجمع إقرارات الفرق تلقائيًا.

## النشر والتخزين
تم تفعيل GitHub Pages من main / root. التغييرات على main يعاد نشرها تلقائيًا.
البيانات محفوظة في المتصفح والجهاز الحاليين فقط، دون مزامنة أو حسابات مستخدمين. استخدم نسخ JSON الاحتياطية باستمرار. لا ترفع بيانات اللاعبين إلى المستودع العام.
النسخ القديمة تبقى قابلة للاستعادة؛ إذا كانت قرعتها لا تتضمن أربع مجموعات فاحفظ نسخة احتياطية ثم احذف القرعة وأعدها بعد استكمال 12–16 فريقًا.
