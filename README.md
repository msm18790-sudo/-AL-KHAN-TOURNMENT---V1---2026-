# THE SQUARE — نظام إدارة بطولة الخان 2026

واجهة عربية متجاوبة تعمل دون تثبيت مكتبات. افتح `index.html` مباشرة أو انشره باستخدام GitHub Pages.

## الوظائف
- تسجيل حتى 64 فريقًا وتعديل أسمائهم، وإضافة اللاعبين بأرقام قمصان فريدة داخل الفريق.
- قرعة عشوائية متوازنة باستخدام Web Crypto، مع تثبيت الفرق بعد القرعة.
- دوري من دور واحد داخل كل مجموعة؛ لا تشمل النسخة أدوار خروج المغلوب.
- توليد جولات دون تكرار المواجهات أو مشاركة الفريق مرتين في الجولة.
- إدخال المواعيد بتوقيت الإمارات والنتائج وتعديلها ومسحها.
- ترتيب تلقائي: النقاط ثم فارق الأهداف ثم الأهداف المسجلة. التعادل الكامل يعطي المركز نفسه؛ الحسم وفق اللائحة خارج النظام.
- نسخ احتياطية JSON واستعادة مع التحقق من سلامة البيانات، وتصدير الترتيب CSV والطباعة.

## تشغيل الموقع على GitHub Pages
من المستودع افتح **Settings → Pages**:
1. ضمن **Build and deployment** اختر **Deploy from a branch**.
2. اختر الفرع **main** والمجلد **/ (root)**.
3. اضغط **Save** وانتظر اكتمال النشر. استخدم رابط الموقع الذي يظهر في صفحة Pages.

رفع الملفات وحده لا يؤكد تفعيل Pages. لم يتم تفعيل خدمة النشر من خلال هذا التحديث.

## الاستخدام
1. افتح «الفرق واللاعبون» وأدخل الفرق واللاعبين.
2. من «القرعة والمجموعات» حدد عدد المجموعات ثم نفذ القرعة.
3. من «المباريات والنتائج» أدخل الموعد والنتيجة بعد انتهاء المباراة. اترك خانتي النتيجة فارغتين لحفظ الموعد فقط.
4. راجع «جدول الترتيب» واحفظ نسخة احتياطية بعد كل تحديث مهم.

## حدود التخزين
البيانات تحفظ في localStorage في المتصفح والجهاز الحاليين فقط. ليست قاعدة بيانات مشتركة، ولا يوجد تسجيل دخول أو نشر تلقائي للنتائج للجمهور. كل زائر يبدأ ببيانات فارغة. مسح بيانات المتصفح قد يحذف البطولة؛ انقل ملف JSON إلى جهاز آخر لاستعادتها. لا ترفع ملفات النسخ الاحتياطية التي تحتوي أسماء اللاعبين إلى هذا المستودع العام.
الانتقال من فتح الملف محليًا إلى رابط Pages أو تغيير المتصفح يحتاج نقل نسخة JSON.

تم اختبار التسجيل والقرعة وتسجيل نتيجة واحتساب الترتيب في المتصفح أيضًا.
